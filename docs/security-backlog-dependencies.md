# Backlog dependency của rexcorp-legacy

Baseline của gate SCA (`osv-scanner.toml`, tạo ngày 2026-10-06) **không** có nghĩa là các lỗ hổng này được chấp nhận. Nó chỉ có nghĩa là "đã biết, đang xử lý", và mỗi mục trong baseline có ngày hết hạn (`ignoreUntil`): Critical 30 ngày, High 60 ngày, còn lại 90 ngày. Hết hạn mà chưa xử lý thì gate lại đỏ.

Số liệu lúc tạo baseline (OSV-Scanner v2.6.0, 2026-10-25): `package-lock.json` có 1091 package; 131 package bị ảnh hưởng (40 package production, 91 package dev); 315 nhóm lỗ hổng, trong đó 33 Critical, 159 High. Dữ liệu advisory thay đổi hằng ngày: số này sẽ khác khi bạn chạy lại.
